> 大一社团寒假项目
> 本项目于 25年3月底制作
## 使用依赖
- **JDK** *17*
- **SpringBoot** *3.4.3*
- **fastjson2** *2.0.56*
- **easyExcel** *4.0.3*
- **lombok** *1.18.36*
- **mybatis** *3.0.4*
## 部署
> 本项目使用 MySQL 数据库如需使用其他数据库请自行修改
1. 将 sql 文件导入数据库
2. 修改 application.yml 文件的 datasource
3. 运行 BookManagementSystemApplication 即可
